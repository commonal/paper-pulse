# 论文解读输出模板

## 模板 A：快速筛读

适用：用户问“这篇论文讲什么”“值不值得读”“先快速看一下”。

```text
# 一句话结论

## 1. 论文在解决什么问题
任务、输入输出、旧瓶颈。

## 2. 作者的核心想法
旧瓶颈 → 关键动作 → 预期收益。

## 3. 实验证据
数据集、主要基线、关键结果、消融是否充分。

## 4. 质量判断
推荐精读 / 选择性精读 / 背景参考 / 暂不投入，并说明理由。

## 5. 待解决问题
第一遍未确认的术语、假设、实验公平性或实现细节。
```

## 模板 B：标准论文解读

适用：用户一般性地要求“解读、梳理、读懂这篇论文”。

```text
# 一句话结论

## 1. 论文基本定位
任务、领域、输入模态、输出、发表状态。

## 2. Abstract：问题—方法—效果
### 2.1 问题
### 2.2 方法与创新
### 2.3 效果
### 2.4 摘要留下的疑问

## 3. 整体处理流程
用一条完整数据流解释主框架图。

## 4. Experiment：论文是否站得住
### 4.1 数据集与实验设置
### 4.2 对比方法
### 4.3 主要定量与定性结果
### 4.4 消融与参数分析
### 4.5 公平性、泄漏和可信度风险

## 5. Introduction：作者为什么这样设计
背景 → 旧方法 → 困难 → 本文方案 → 贡献。

## 6. Approach：方法如何实现
逐模块说明目的、输入、操作、输出、作用和实验依据。

## 7. 核心公式
公式问题、变量、运算、直觉和整体作用。

## 8. Related Work：技术位置
本文属于哪条路线，与直接相关工作有什么真实差异。

## 9. 综合评价
创新性质、证据边界、局限、复现难度、适用场景。

## 10. 对当前研究的启发
可迁移机制、可用 baseline、可借鉴实验、不可直接照搬的部分。

## 11. 待解决问题清单
标记已解决、部分解决、未解决。
```

## 模板 C：方法与公式精读

适用：用户明确要求细读 Approach、推导公式、复现方法。

```text
# 方法总览

## 1. 任务定义与符号
输入、输出、标签、维度和假设。

## 2. 端到端数据流
训练路径与推理路径。

## 3. 模块一
目的 → 输入 → 操作 → 输出 → 作用 → 证据。

## 4. 模块二
同上。

## 5. 损失函数与优化目标
总损失组成、每项作用、权重和训练影响。

## 6. 关键公式逐项拆解
每个公式按“问题—变量—运算—直觉—作用”解释。

## 7. 维度与张量流
必要时列出 shape 变化和对齐关系。

## 8. 训练与推理伪代码
只保留实现所需的关键步骤。

## 9. 复现清单
数据、预处理、配置、依赖、权重、随机种子和风险。

## 10. 消融对应关系
每个设计选择由哪项实验支持。
```

## 模板 D：组会或教学讲解

适用：用户需要口语化汇报、演示文稿或教学解释。

```text
# 这篇论文一句话在做什么

## 1. 为什么需要这项工作
用真实场景和旧方法困难开场。

## 2. 作者的核心想法
先通俗比喻，再给术语。

## 3. 整体流程
按输入 → 模块 → 输出讲解，不先讲公式。

## 4. 最关键的 1–3 个模块
每个模块回答“为什么、怎么做、带来什么”。

## 5. 核心公式
只保留汇报必须的公式，并提供口语讲法。

## 6. 实验怎么证明
数据集、基线、主要结果和消融。

## 7. 这篇论文真正贡献了什么
区分实质创新与工程组合。

## 8. 局限和可讨论点
为提问环节准备。
```

## 模板 E：指定论文直接对比

适用：用户明确给出两到数篇论文，要求比较方法、实验或研究价值。

```text
# 对比结论
先说明比较维度、可比范围和最重要差异。

## 1. 任务与实验口径是否可比
数据集、划分、模态、指标、预训练和计算预算。不可比项先声明。

## 2. 每篇论文的核心机制
分别写成“旧瓶颈 → 关键动作 → 预期收益”。

## 3. 方法层对比
输入、编码、交互/融合、训练目标、输出和复杂度。

## 4. 证据层对比
强基线、主要结果、消融、稳定性、泛化与复现条件。

## 5. 结论边界
区分“在共同设置下更强”与“因设置不同无法直接判定”。

## 6. 阅读与研究建议
哪篇适合精读、作 baseline、借鉴机制或仅作背景。
```

## 写作要求

- 先结论后展开。
- 不逐段翻译，不机械复述目录。
- 数字结果必须说明数据集、指标、对比对象和可比条件。
- 通俗解释和术语表达配套出现。
- 表格只用于确实需要横向比较的内容。
- 用户未要求长文时，优先使用模板 A 或模板 B 的压缩版。
- 在正文中用 `[Paper §x]`、`[Paper Fig. x]`、`[Paper Table x]` 等最窄定位标记关键依据。
