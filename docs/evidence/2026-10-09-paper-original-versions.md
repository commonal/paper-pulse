# 同篇原文版本管理验收

日期：2026-10-09；本机网站：http://127.0.0.1:5321。

## 已实现行为

一篇论文可关联多份原文。当前版本继续使用现有阅读流水线；切换时事务保存旧PDF、正文、双语展示、解读、图表和任务快照，再恢复目标版本。个人收录、代码链接和阅读状态保持论文级，笔记按原文件定位。历史GET只读，不切换、不调用模型；历史图表升级入口关闭，引用和原文使用明确的版本参数。PDF阅读组件在版本变化时重新建立，页码重置，避免沿用另一份文件的页数或画布。

添加版本需确认同篇归属，允许选择身份预览中的arXiv、DOI或本地候选记录；自动核验仍只是身份线索，不宣称两份正文内容等价。相同哈希的PDF复用已有版本，不覆盖当前原文。过期页面的版本写入、跨论文版本编号、未结束的任务、队列作业或未知回执均拒绝切换。

arXiv发现新vN仅新增待选择版本，不清空旧文或购买新解读。已精读库在当前版本没有文章时仍可进入历史已完成文章。0093–0096已应用；单独回填采用467篇原论文，不在迁移内批量回填。
