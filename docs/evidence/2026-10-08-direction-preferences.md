# 关注方向与检索设置验证（2026-10-08）

## 本次实现

八个个人预设方向与独立 AI 热点计划，共用分类、主题、关键词和排除规则。页面支持关注、重点关注、三个细分主题、标题精确匹配或标题/摘要广泛匹配；高级自定义保留分类与关键词，预设模式另提供补充匹配词。补充词是额外 OR 条件，不是必须同时满足的限制；排除词始终核查标题与摘要。

方向规则在 arXiv 采集、当前候选核查、每日入选、本地预览与后续 OpenAlex 周检索中复用。arXiv 分类是来源分类，页面方向是本项目整理的产品主题，两者不等同。预设默认标题匹配；英文按规范化词组边界匹配，连字符视为空格，中文按子串匹配。`RAG` 不命中 `fragility`，主题内同义词 OR、所需词组 AND，多个主题 OR。

每日热点最多一个名额；个人方向按近七天主推荐次数从少到多轮换，次数相同按重点关注、上次主推荐日期、固定方向 ID 排序。方向内使用已有评分及发表日期，不另造评分门槛。同篇跨方向去重，保留全部命中方向和一个主推荐方向。每天最多三篇的配额不因增加方向改变。

新增迁移为 `0081_paper_plan_preferences.sql`、`0082_paper_queue_primary_plan.sql`、`0083_papers_arxiv_categories.sql`，各一条 nullable 列 DDL；本机执行成功，未改历史迁移或删除论文数据。

## 验证边界

本地预览只读取最近收录的最多500篇元数据，最多展示20篇，不是对外部信源的实时全量检索。旧候选缺全量来源分类时使用已保存匹配分类；新采集会保存来源分类。旧推荐主方向为空，不回填推断历史，因此轮换统计从新增归属记录开始建立。

词组匹配是可解释的规则，不保证语义相关性或召回率；现有英文词形、摘要缺失、信源索引及同义词覆盖都可能影响结果。开启精准范围可能漏掉标题未出现关键词的相关论文，应通过本地预览调整。当前已入选论文保留；高引结果的历史缓存仍按原35天有效期展示，后续周检索才使用新查询条件，不在保存设置时付费刷新。

arXiv `ti` / `abs`、AND / OR / ANDNOT 对应 [官方 API 手册](https://info.arxiv.org/help/api/user-manual.html)。OpenAlex 使用标题或标题/摘要搜索、引号词组及布尔表达式，对应 [官方搜索说明](https://help.openalex.org/api/searching/)。代码对过长高引查询明确报错并要求减少关键词，没有自动拆分增加请求。OpenAlex 新规则已通过本地假服务测试，此次未手动触发真实外部高引检索。
