# 默认日更阅读流程验证（2026-10-07）

本轮范围：将原单篇 Skill 试验接入默认论文队列，串联覆盖检查、精读、独立原文核查、自动图表；补齐等待、恢复和页面进度。不包含新闻与论文导航整合。

## 已实现

- 新建 `paper_reading_tasks` 保存当前任务编号、阶段、选项、覆盖报告和回执；旧文章与任务状态分别保存。
- 默认日更和手动入口使用 `paper-reading-v2@51d637c94f77`，删除单次旧解读与独立展示补齐的生成代码和对应测试；历史发布内容仍读取。
- 预算不足、模型服务关闭和未知结果进入等待，恢复调度保留任务编号及选项；内容校验失败需显式重试。
- 精读及核查完整回答按精确输入复用；原文核查返回片段编号，系统取回原句，补齐缺失的来源引用并保留修复记录。未知片段、缺失主张和不真实摘录仍拒绝。
- 新任务取代旧任务后，旧任务不能发布；图表阶段遇到解读失效会重新进入正文处理，不误报完成。
- 已有文章继续可读；页面提供各阶段、覆盖信息、继续处理和重新精读。页面读取不调用付费服务。
