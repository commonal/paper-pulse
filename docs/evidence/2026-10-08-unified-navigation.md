# 统一网站入口验证（2026-10-08）

## 范围与结果

按已确认的四组组织桌面侧栏：阅读、发现、AI 资讯、个人与设置；窄屏底栏对应阅读、发现、资讯、我的。新闻精选、全部动态、热点榜、日报/周报、主题、新闻收藏和 Agent 接入等原有页面继续使用原地址。导航由论文模块提供，壳层新增通用配置插口，没有把论文路径写进框架侧栏。

补齐全部论文与阅读记录，支持关键词与阅读状态共同筛选，最多返回最近收录的 200 篇。阅读记录默认显示手动标记为阅读中或已读的论文；本地停留 ≥30 秒的统计保留独立含义。论文详情显示来源列表的返回入口、保留筛选，并继承来源分组高亮；直接打开详情时归入阅读。

真实点击发现：React Router Single-fetch 请求的 loader URL 保留 `.data` 后缀，原先按精确路径识别列表会把阅读记录识别为今日阅读。已修正，并加入实际生产 Web 服务的 HTML/Single-fetch 回归，核对读取端点和查询参数。窄屏候选卡片也因长命中说明产生横向溢出，已通过收缩网格卡片及文本换行修复。
