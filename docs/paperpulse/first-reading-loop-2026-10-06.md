## 样本与证据

本轮产品验收主线已从“个人笔记闭环”收敛为“论文热点 → 正文解析 → AI 解读 → 证据回跳”。下述笔记创建/编辑记录是早期底座能力的历史验收证据，不代表当前详情页继续把手写笔记作为主流程。

公开论文 [Attention Is All You Need / arXiv v7](https://arxiv.org/abs/1706.03762v7)，原文 [PDF](https://arxiv.org/pdf/1706.03762v7)。关联 [Tensor2Tensor](https://github.com/tensorflow/tensor2tensor) 仓库链接；该仓库已归档，仅验证资料关联，未运行代码。论文元数据依据 arXiv，摘要未预填，避免把演示内容当作原始摘要。

首篇记录 ID：`397a976a-fd41-4f06-91d5-75b59133e60f`。PDF 2,215,244 字节，PDF.js 解析为 15 页，存取后的字节一致。SHA-256：`bdfaa68d8984f0dc02beaca527b76f207d99b666d31d1da728ee0728182df697`。

导入使用真实 HTTP API。浏览器实际打开首页、详情和 PDF；早期版本曾创建“模型结构图：待核对问题（验收示例）”笔记，再编辑保存。笔记标注为验收示例，不代表用户已经完成精读。其出处为 PDF 第 3 页 Figure 1。

点击笔记出处后，页码从 1 变为 3，PDF.js 重新显示第 3 页。重启 API/web 后，该笔记仍存在，revision 为 2、页码为 3，版本和 PDF 校验值仍与原文记录一致。标准导出接口返回包含论文、版本、原文链接、笔记内容及页码的 Markdown，HTTP 200。

截图、运行状态和日志保存在忽略 Git 的 `.local/`；原文副本与笔记持久化在独立数据库。服务端返回私人数据时禁止共享缓存。

## 全量回归的限制

后端全量运行统计：700 项，680 通过，15 失败，5 取消；不能称为全量通过。已观察的限制包括 Windows SIGTERM 测试超时、缺少本机 pg_dump/sh、openssl 证书命令失败，以及两个测试文件因测试数据库名称/PID 重用而未执行。这两个文件（signals/site-routes）单独重跑共 5 项通过。其余底座运维行为未在本轮修复，尤其不能声称备份恢复和优雅退出已通过。

更新测试目标后的网页回归为 49 项，36 通过，13 失败：失败组依赖未安装的 Playwright 浏览器。保留原始测试与失败记录，没有删掉或标成成功。浏览器交互使用当前内置浏览器另行验收，不替代整套 Chromium/WebKit 回归。

首次回归错误地继承了本地开发开关，已终止并改成独立测试配置后重跑。测试配置只提供 *_test 数据库和 NODE_ENV=test，模型由上游测试指向本地假服务，不使用真实模型密钥。备份错误日志中的连接串已脱敏，新项目本地数据库密码已轮换。

内置 PDF 插件曾显示空白，已用 PDF.js 替换并实际确认显示正文。最初的 Blob 下载验收等待超时，导出改为受保护的标准 HTTP 下载接口，文件内容与访问限制通过验证；浏览器下载管理器中的落盘位置未验收。
